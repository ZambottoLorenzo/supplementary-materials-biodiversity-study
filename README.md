# Supplementary materials: Serious game evaluation and study

This repository contains supplementary artifacts, telemetry analyses, survey instruments, and playable game builds.

---

## Repository contents

### 1. Evaluation instruments and questionnaires
* **[`questionnaires.md`](./questionnaires.md):** Complete transcript of all participant instruments administered during the study:
  * **Pre-Game Baseline Survey:** Demographics, video game experience, geographic residence (Trentino / Outside), site familiarity (Lago di Toblino), and baseline species/habitat knowledge items.
  * **Post-Game Evaluation Survey:** Knowledge post-test, Mini Player Experience Inventory (MiniPXI), EGameFlow Knowledge Improvement subscale, educational takeaway questions, conditional AI perception subscale, and qualitative feedback prompts.

### 2. Telemetry and data analyses
* **[`Finished Telemetry Files Analysis.pdf`](./Finished%20Telemetry%20Files%20Analysis.pdf):** Detailed statistical breakdown and visualization of telemetry logs for participants who completed the game playthrough.
* **[`Game Incomplete Telemetry Files Analysis.pdf`](./Game%20Incomplete%20Telemetry%20Files%20Analysis.pdf):** Telemetry data records for participants who completed the tutorial but did not finish the main game.
* **[`Tutorial Incomplete Telemetry Files Analysis.pdf`](./Tutorial%20Incomplete%20Telemetry%20Files%20Analysis.pdf):** Telemetry data records for participants who dropped off during the tutorial phase without completing it.

### Quick start instructions
1. Navigate to **Releases** on the right sidebar and download the appropriate package for your system (`.zip`).
2. **Extract/Unzip** the archive completely before running (the game will not launch properly from within a compressed folder).
3. **Launch the Executable:**
   * **Windows:** Open the extracted folder and run `Final Exam.exe`.
   * **macOS:** Open the extracted folder and double-click `Project Trentino.app`. *(Note: If macOS Gatekeeper blocks execution, open **System Settings > Privacy & Security**, scroll to Security, and select **Open Anyway**).*
   * **Linux:** Run the `Project Trentino` binary. *(Untested build; minor performance variation may occur).*
